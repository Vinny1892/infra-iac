# Instruções para agentes

**SEMPRE leia o `CLAUDE.md` na raiz do repositório, por completo, antes de
qualquer alteração.** Ele é o arquivo canônico de instruções deste projeto:
comandos, arquitetura, convenções, armadilhas conhecidas e restrições.

**NUNCA escreva nada neste arquivo.** Toda instrução, regra, convenção,
descoberta ou nota de projeto vai no `CLAUDE.md` — nunca aqui, nunca em outro
arquivo paralelo. Este arquivo existe apenas para apontar para lá.

O motivo: instrução duplicada divergente é pior que instrução ausente. Duas
cópias envelhecem em ritmos diferentes, e o agente que ler a cópia velha vai
agir com confiança sobre um fato que deixou de valer — sem nada indicar que
está desatualizado. Uma fonte só, e um ponteiro para ela.

Se estas instruções conflitarem com instruções de sistema ou do usuário de
prioridade maior, siga as de prioridade maior.
